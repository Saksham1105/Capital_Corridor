# Capital Corridor

Capital Corridor — Structured Finance • Investment Advisory • Capital Market Solutions.

## Live Website
- **Primary:** https://capitalcorridor.in/
- **WWW:** https://www.capitalcorridor.in/

## About
Capital Corridor is a leading financial advisory, structured finance, investment banking advisory, and capital markets solutions firm specialising in funding, debt syndication, capital raising, and strategic financial advisory. We help corporates, entrepreneurs, developers, financial institutions, family offices, and investors access capital through our robust institutional network.

## Website Features
- Responsive and premium editorial design
- Optimized for speed, accessibility, and high performance
- Static client-side routing
- Fully optimized SEO and JSON-LD structured metadata
- Clean semantic HTML layout tailored for corporate advisory presentation

## Technology Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion (via motion/react)
- **Icons:** Lucide React
- **SEO & Head Management:** React Helmet Async

## Project Structure
- `/src/pages`: Contains the core routing components for the website.
- `/src/components`: Contains global UI elements (Header, Footer, SEO wrapper).
- `/public`: Houses static assets including `robots.txt` and `sitemap.xml`.

## SEO
The platform utilizes comprehensive Search Engine Optimization:
- Unique canonical URLs for all routes
- Tailored meta titles and descriptions
- Valid `Organization` JSON-LD schema injected into the homepage
- Prioritized sitemap mapping in `/public/sitemap.xml`
- Explicit web crawler access defined in `/public/robots.txt`

## Local Development
To run this project locally:

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

## Production Build
To create an optimized production build:

```bash
npm run build
```
